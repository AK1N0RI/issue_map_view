Issue Map View Settings

Configure a fine-grained personal access token (PAT) with access to the target repository. Grant these repository permissions:

  • Issues: Read and write — list, create, update, and link Analysis Result and Countermeasure issues.
  • Pull requests: Read and write — list pull requests and add issue references to their descriptions.
  • Projects: Read and write — view and edit Project v2 membership.

The token is stored only for the current browser session and is removed when the browser session ends or the extension is reloaded.

The token itself is never displayed again. To replace it, enter a new token and save it.
