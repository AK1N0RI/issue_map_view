Issue Map View Settings

Configure a fine-grained personal access token (PAT). The token requires access to the target repository and Issues: Read and write permission. Pull requests: Read permission is required to check the status of pull requests linked to countermeasures. Projects: Read and write permission is required to view and edit Project v2 membership. The token is stored only for the current browser session and is removed when the browser session ends or the extension is reloaded.

The token itself is never displayed again. To replace it, enter a new token and save it.
