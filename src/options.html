Issue Map View 設定

Fine-grained personal access token (PAT) を設定します。対象リポジトリへのアクセスと Issues: Read and write 権限が必要です。対策に紐づくPull Requestの状態確認には Pull requests: Read 権限、Project v2の表示・編集には Projects: Read and write 権限も必要です。PATはブラウザーまたは拡張機能を再起動・再読み込みするまでのセッション中のみ保存されます。

PAT自体は画面に再表示されません。変更する場合は新しいPATを入力して保存してください。
